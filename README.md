# Visualization tools for AutoMeKin-X
[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/ComputationalChem-USC/amk_tools_X/blob/master/notebooks/amk_tools.ipynb)

**amk_tools_X** is the version of *amk-tools* maintained by the [ComputationalChem-USC](https://github.com/ComputationalChem-USC) group for [AutoMeKin-X](https://github.com/ComputationalChem-USC/AutoMeKin-X). It is based on the original [amk_tools](https://github.com/dgarayr/amk_tools) by Diego Garay-Ruiz (2021, Institute of Chemical Research of Catalonia, Prof. Carles Bo Research group), updated to run in the same Python environment as AutoMeKin-X (Python 3.11, numpy 2.x, Bokeh 3.x).

## What is new in amk_tools_X
- **numpy 2 and Bokeh 3 support.** The original package required `numpy<2` and `bokeh<3`, which clashed with the packages AutoMeKin-X installs (for example, fairchem-core 2.x needs numpy >= 2). amk_tools_X now works with numpy 2.x and Bokeh 3.4 to 3.9.
- **JSmol embedded in the dashboard.** The *jsmol_bokeh_extension* package (Bokeh 2 only) and NodeJS are no longer needed. JSmol is loaded from a CDN when the HTML file is opened.
- **New dashboard design.** White, blue and black layout with the AutoMeKin-X logo and a link to its repository, a menu bar, the 3D viewer on the left, the network on the right, and the energy profiles and reaction schemes at the bottom.
- **Command-line tools installed with the package.** `amk_gen_view.py` and `amk_rxn_stats.py` are copied into the environment's `bin/` folder, so there is no need to add the *scripts* folder to `$PATH`.

## Basic features
The library reads, processes and visualizes the reaction networks generated by [AutoMeKin-X](https://github.com/ComputationalChem-USC/AutoMeKin-X) (and the original [AutoMeKin](https://github.com/emartineznunez/AutoMeKin)). It is organized in two modules:

- RXReader (**arx**). Parses & processes the *RXNet* files generated by AutoMeKin to NetworkX.Graph objects containing all the information about the network: connectivity, energies, XYZ geometries and frequencies for every intermediate and transition state. Moreover, contains functions to fetch paths in the network and basic Matplotlib-based plots for networks and energy profiles.
- RXVisualizer (**arxviz**). Generates Bokeh-based interactive dashboards for the reaction networks processed by *RXReader*, containing:
    - Interactive network plot, allowing the user to zoom and move around. Hovering over nodes or edges shows the corresponding name and energy.
    - JSmol instance to display 3D models of the selected node/edge in the network, including vibrational normal modes.
    - Visualization of energy profiles along the network, which may be filtered by energy or by the presence of a given species.

These dashboards are generated as independent HTML files, not requiring a live Python server.

## Installation
It is recommended to install amk_tools_X inside the conda environment used by AutoMeKin-X, or in a dedicated environment with Python 3.11.

Install directly from GitHub:

```
pip install git+https://github.com/ComputationalChem-USC/amk_tools_X.git
```

Or clone the repository and install it in *editable* mode, so that changes in the **py** files of RXReader and RXVisualizer are applied directly wherever the modules are used:

```
git clone https://github.com/ComputationalChem-USC/amk_tools_X.git
cd amk_tools_X
pip install -e .
```

To check the installation:

```
python -c "import RXReader, RXVisualizer, bokeh, numpy; print(bokeh.__version__, numpy.__version__)"
amk_gen_view.py --help
```

If an older *amk_tools* (from dgarayr/amk_tools) is installed in the same environment, uninstall it first (`pip uninstall amk_tools jsmol_bokeh_extension`) and remove its *scripts* folder from `$PATH`, so that the new version is the one used.

## Usage guidelines
The simplest way to generate a dashboard from AutoMeKin results is the `amk_gen_view.py` script:

```
amk_gen_view.py FINALDIR RXNFILE [options]
```

where **FINALDIR** is the folder containing AMK results (for example `FINAL_HL_MOL`) and **RXNFILE** is the name of the RXNet file to be used (RXNet, RXNet.cg or RXNet.rel). Additional arguments that may be passed are:

- **--barrierless, -b**. Include the barrierless routes stored in *RXNet.barrless*.
- **--vibrations NVIBR, -v**. Add only *NVIBR* normal modes to the visualization. Default is -1, meaning that ALL modes are included.
- **--ref_state STATE, -rs**. Reference state for the energies.
- **--paths [SOURCE] [TARGET], -p**. Locate paths in the network connecting SOURCE to TARGET, to include energy profile visualizations in the dashboards. When both SOURCE and TARGET are specified, a simple search is performed including only the routes that connect both nodes. If *--paths* is passed without further specification, all possible cyclic paths along the network are searched (much slower). If only SOURCE is specified, all cyclic paths are also searched, and then filtered to only keep these with connections to SOURCE.
- **--cutoff_path CUTOFF, -c**. Maximum depth for two-ended path search (number of intermediate nodes between SOURCE and TARGET), default is 4.
- **--efilter ENERGY, -e**. Energy threshold for path selection, in kcal/mol. By default no filtering is done.
- **--unreduced, -u**. Generate the full graph, without excluding nodes that are not in the paths.
- **--geomolden, -ng**. Update geometries from the MOLDEN files.
- **--outfile FILENAME, -o**. Name of the output HTML file containing the dashboard (default *network.html*).
- **--title TITLE, -t**. Title shown in the dashboard.
- **--resolution WIDTH,HEIGHT, -r**. Size of the HTML visualization in pixels (default 1400,800).
- **--fasterlayout, -f**. Use the faster `nx.spring_layout` for the network layout.

For example:

```
amk_gen_view.py FINAL_HL_FA RXNet.cg --barrierless --paths MIN1 --outfile network.html
```

The `amk_rxn_stats.py FINALDIR` script computes statistics of the reaction network (see `amk_rxn_stats.py --help`).

If more control is desired, the user should use a custom Python script: see the [UserGuide](UserGuide.md) for the Python workflow and a reference script.

## Dependencies
Aligned with the environment installed by [AutoMeKin-X](https://github.com/ComputationalChem-USC/AutoMeKin-X) (Python 3.11, numpy 2.x):

+ Python >= 3.10
+ NetworkX >= 3.0
+ Bokeh 3.x (>= 3.4, < 4.0; 3.9 is the last series supporting Python 3.10/3.11)
+ numpy >= 1.24 (numpy 2.x supported)
+ scipy >= 1.10
+ matplotlib >= 3.7

All of them are installed automatically by `pip`. Bokeh 2.x is no longer supported: it does not work with numpy 2, which AutoMeKin-X installs.
